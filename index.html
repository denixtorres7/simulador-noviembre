Cómo funciona

La interfaz principal organiza la navegación y las preferencias visuales. Cada calculadora conserva su código separado. La información compartida entre módulos se conectará mediante contratos de datos versionados y una base persistente.

Estado de esta versión: demostración local de interfaz y aislamiento. No incluye cuentas, base de datos, sincronización entre dispositivos, retroalimentación docente ni generación consolidada de documentos.

La aplicación Canvas es independiente y no forma parte de este producto.
